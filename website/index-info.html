Informações sobre o Website

Este Website é um projeto para exercício final para a disciplina de Tecnologias Web. O projeto consiste em uma página web que apresenta uma coleção de gifs relacionados a uma cidade e uma aldeia. O objetivo é demonstrar habilidades em HTML e CSS.

A página inclui um cabeçalho com um logotipo, um botão de informações e filtros para selecionar entre gifs de cidade ou aldeia. A seção principal exibe os gifs correspondentes à categoria selecionada.
